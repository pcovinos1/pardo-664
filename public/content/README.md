# Contenido publicado de Pardo 664

1. En el administrador, abre **Configuración → Publicar en este dispositivo** para generar una versión nueva.
2. Selecciona **Descargar project.json** y reemplaza `public/content/project.json`.
3. Haz commit y push para que GitHub Pages publique la actualización en `/pardo-664/`.
4. Las tablets sin cambios locales descargarán la versión al volver a conectarse. En las tablets con cambios guardados, usa **Sincronizar desde GitHub** para revisarla manualmente.
